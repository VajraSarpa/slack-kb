**Where retries are handled**
- `reference/tutorial/lambda/ingestion/handler.py:30-33` is the actual handling [obs_63462000daa8].
  - Line 28 lowercases the request headers.
  - Line 31 checks `headers.get('x-slack-retry-num') or headers.get('x-slack-retry-reason') == 'http_timeout'`.
  - If either matches, lines 32-33 log "Slack retry detected" and return `{'statusCode': 200, 'body': ''}` straight away.
